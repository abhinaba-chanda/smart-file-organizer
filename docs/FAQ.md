# FAQ

**Does it delete files?**
No. Files are only moved into category folders. Duplicates are reported, not removed.

**Can I preview before moving?**
Yes, use the dry run option to see the plan first.

**Can I change the categories?**
Yes, copy `default_config.yaml`, edit the extension lists and pass it with the config option.

**Which Python version?**
Python 3.9 or newer.
